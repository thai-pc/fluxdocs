# Third-party notices

FluxDocs code is licensed under the MIT License (`LICENSE`). The default
build also bundles the font data listed below, which keeps its own licenses.
It is used to draw PDF text set in the 14 standard fonts (and other fonts a
PDF does not embed). A binary built with `-tags nostd14` leaves the font
faces (sections 1 and 2) out. The metric and glyph-name tables (sections 3
and 4) are always included.

Distribute this file and the license files it names with any binary built
from FluxDocs, `fluxdocs.wasm` included. The npm package `@fluxdocs/core`
ships a copy of this file. A license file named `LICENSES/<name>` below is
`core/internal/std14/LICENSES/<name>` in the FluxDocs repository and
`LICENSES/<name>` in the npm package.

All files below are generated by `testing/tools/std14fonts` from the
upstream files listed under "Sources". The tool refuses inputs whose SHA-256
differs from the pinned value, and its output is deterministic.
`core/internal/std14` tests check that every listed file exists and matches
its SHA-256 here, so a changed face or table fails CI until this file is
updated.
